# 🍜 Food Ordering and Kitchen System

> A Java-based food ordering system with a working kitchen terminal.

## About the App

The Food Ordering and Kitchen System is a Java Swing-based food ordering system with an integrated kitchen terminal for order management, receipt printing, and real-time order display.

## Preview

## Features
- Kiosk start up
- Menu showcase
- Calculator
- Qty, Item, Price Table
- Total order calculation
- Cancel and Done order
- Kitchen Terminal
- Automatic PDF Receipt printing

## 🚀 Running from Source

### Requirements

- Java JDK 25
- NetBeans (recommended)

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/kiacodesss/food-ordering-and-kitchen-system.git
   ```
   
2. Open the project in NetBeans.
3. Allow NetbBeans to load the required dependencies.
4. Create a "Kitchen Terminal" folder in your Local Disk.
5. Create a "Orders.txt" file inside the Kitchen Terminal Folder. 
6. Build the project.
7. Run the application.
